## Privacy

- **No cookies, no tracking, no analytics.** The website sets no cookies and embeds no third-party content. Fonts are served by this website itself.
- **Hosting:** The website is served via GitHub Pages (GitHub, Inc., USA). When you visit, GitHub processes technically necessary data such as your IP address in server log files. Details: [GitHub privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
- **Search:** The full-text search runs entirely in your browser. Search terms are not sent to a server.
- **RSS feed:** The feed is a public file on this website. Subscribing to it in a feed reader does not pass any personal data to the project.
- **Email notifications:** If you want to receive new documents by email, you sign up via a form of our email service Brevo (Sendinblue SAS, Paris, France). Your email address and consent are stored; you must confirm the sign-up via a confirmation link (double opt-in). The data is used only to send the notifications. Every email contains an unsubscribe link; after unsubscribing, the address is no longer used. Details: [Brevo privacy policy](https://www.brevo.com/legal/privacypolicy/).
- **Contributions via GitHub:** Opening an issue or proposing changes happens on GitHub and is subject to GitHub's terms. Contributions are publicly visible.
