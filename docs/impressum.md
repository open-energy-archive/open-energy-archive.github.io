## Datenschutz

- **Keine Cookies, kein Tracking, keine Analyse-Tools.** Die Website setzt keine Cookies und bindet keine Inhalte von Drittanbietern ein. Schriften werden von dieser Website selbst ausgeliefert.
- **Hosting:** Die Website wird über GitHub Pages bereitgestellt (GitHub, Inc., USA). Beim Aufruf verarbeitet GitHub technisch notwendige Daten wie die IP-Adresse in Server-Logfiles. Details: [GitHub-Datenschutzerklärung](https://docs.github.com/de/site-policy/privacy-policies/github-general-privacy-statement).
- **Suche:** Die Volltextsuche läuft vollständig im Browser. Suchbegriffe werden nicht an einen Server übermittelt.
- **RSS-Feed:** Der Feed ist eine öffentliche Datei auf dieser Website. Wer ihn in einem Feed-Reader abonniert, gibt dabei keine Personendaten an das Projekt weiter.
- **Benachrichtigung per E-Mail:** Wer neue Dokumente per E-Mail erhalten möchte, meldet sich über ein Formular unseres E-Mail-Dienstes Brevo an (Sendinblue SAS, Paris, Frankreich). Dabei werden die E-Mail-Adresse und die Einwilligung gespeichert; die Anmeldung muss per Bestätigungslink bestätigt werden (Double-Opt-in). Die Daten werden nur für den Versand der Benachrichtigungen verwendet. Jede E-Mail enthält einen Abmeldelink; nach der Abmeldung wird die Adresse nicht mehr verwendet. Details: [Datenschutzerklärung von Brevo](https://www.brevo.com/de/legal/privacypolicy/).
- **Beiträge über GitHub:** Wer ein Issue eröffnet oder Änderungen vorschlägt, tut dies über GitHub; dafür gelten die Bedingungen von GitHub. Beiträge sind öffentlich sichtbar.
